# Thai web fonts

Headings: IBM Plex Sans Thai (600, 700)
Body text: IBM Plex Sans Thai Looped (400, 500, 600)

Source: Google's fonts repository, directories `ofl/ibmplexsansthai` and
`ofl/ibmplexsansthailooped` at https://github.com/google/fonts.

These are unmodified font files. The corresponding SIL Open Font License files
are included alongside the fonts. Fonts are served locally with `next/font/local`.
